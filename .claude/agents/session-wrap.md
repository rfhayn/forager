# Session Wrap-Up

Ensure all session documentation is current before the final commit.

## Process

1. **Insights check**: Review recent changes for any unlogged technical insights. If found, log them.
2. **Journal update**: Write or update the development journal entry for this session.
3. **Commit readiness**: Review staged/unstaged changes and prepare the commit.

Report what was updated and confirm readiness to commit.
