Recommendation: Option A

Option A (Full Search Sheet) is the strongest choice because it already exists as RecipePickerSheet.swift with search, servings adjusters, household scope filtering, and empty states all built. The implementation is a one-line change — swap the Menu for a .sheet that presents RecipePickerSheet. It's also the pattern you already know works well — you described it as "a text box that would search recipes to quickly reduce the list" which is exactly what RecipePickerSheet does. If Option C's compactness appeals, it could be a future enhancement, but Option A delivers the fix with zero new code.
