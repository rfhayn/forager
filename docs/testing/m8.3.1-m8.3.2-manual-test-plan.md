# Manual Test Plan: M8.3.1 + M8.3.2

**Covers**: Template Name Hygiene, Confidence Badge, Auto-Merge Grocery Quantities
**Prerequisite**: Clean build on iPhone 17 Pro simulator
**Estimated Time**: 15-20 minutes

---

## Setup

1. Build and launch on simulator
2. Delete all existing test recipes (if any) via swipe-to-delete on Recipes tab
3. Go to Ingredients tab → Edit → select all → delete (to clear stale templates)
4. Generate fresh test recipes: Recipes tab → hamburger menu or "+" → generate sample recipes

---

## Section 1: Template Name Hygiene (M8.3.1)

**Goal**: Verify the Ingredients tab shows only pure ingredient names, no quantities or units.

### Test 1.1: Template names from test recipes
1. Navigate to **Ingredients** tab
2. Scroll through all entries

**Expected**: Names like "garlic", "sour cream", "cilantro", "chicken broth", "cayenne", "black beans", "diced tomatoes", "tortilla strips"
**Fail if**: Any entry contains quantities like "Two Cloves Garlic", "½ Cup Sour Cream", "1 Can (15 Oz) Black Beans"

### Test 1.2: No duplicate templates
1. On **Ingredients** tab, search for "garlic"
2. Search for "chicken broth"
3. Search for "butter"

**Expected**: Exactly one template per ingredient name
**Fail if**: Multiple entries for the same ingredient (e.g., "garlic" + "Two Cloves Garlic")

### Test 1.3: New recipe creates clean templates
1. Go to **Recipes** tab → **+** to create new recipe
2. Add ingredients: "3 cups all-purpose flour", "1 tsp vanilla extract", "2 large eggs"
3. Save the recipe
4. Go to **Ingredients** tab

**Expected**: New entries "all-purpose flour", "vanilla extract", "large eggs" (or "eggs") — no quantities
**Fail if**: Entries like "3 Cups All-Purpose Flour"

### Test 1.4: Edit recipe preserves clean templates
1. Open the recipe from Test 1.3
2. Edit it and add a new ingredient: "½ cup brown sugar"
3. Save
4. Check **Ingredients** tab

**Expected**: New entry "brown sugar" — no quantity
**Fail if**: Entry contains "½ Cup Brown Sugar"

## Section 2: Yellow Confidence Badge (M8.3.1)

**Goal**: Verify the yellow triangle badge appears on low-confidence parsed ingredients.

### Test 2.1: Badge visible on recipe detail
1. Navigate to **Recipes** tab
2. Open "Simple Seasoned Rice" (Recipe 12)
3. Look at the ingredient list

**Expected**: Yellow triangle badge visible on:
- "a pinch of saffron" (confidence ~0.60)
- "butter (room temperature, European-style, about 2 tablespoons or so)" (complex/unparseable)
- Possibly "fresh herbs to garnish"

**Fail if**: No yellow badges visible anywhere

### Test 2.2: Badge visible on grocery list
1. Create a new grocery list
2. Add "Simple Seasoned Rice" ingredients to the list
3. Check the grocery list

**Expected**: Yellow badge on the same low-confidence items
**Fail if**: No yellow badges on grocery list items

### Test 2.3: High-confidence items have no badge
1. On the same recipe detail, check "2 cups rice"

**Expected**: No yellow badge (confidence ~0.95)
**Fail if**: Badge appears on standard high-confidence items

## Section 3: Auto-Merge Grocery Quantities (M8.3.2)

**Goal**: Verify that adding the same ingredient from multiple recipes automatically sums quantities.

### Test 3.1: Same-unit numeric merge
1. Create a new grocery list
2. Open a recipe with chicken broth (e.g., "Hearty Tortilla Soup" — 1.5 cups)
3. Add its ingredients to the grocery list
4. Open a second recipe with chicken broth (e.g., "Simple Seasoned Rice" — 2 cups)
5. Add its ingredients to the same grocery list

**Expected**: Grocery list shows a single "chicken broth" entry with **3.5 cups** (1.5 + 2.0), tagged with both recipes
**Fail if**: Two separate "chicken broth" entries, or a string like "1.5 cup + 2.0 cup"

### Test 3.2: Source recipe tracking
1. On the merged "chicken broth" entry from Test 3.1, check if source recipes are visible (if UI shows this)

**Expected**: Both recipe names associated with the item
**Fail if**: Only one recipe shown

### Test 3.3: First add (no merge needed)
1. Create a fresh grocery list
2. Add ingredients from a single recipe

**Expected**: All items appear with correct quantities, no merge artifacts
**Fail if**: Any item has incorrect quantity or missing display text

### Test 3.4: Unparseable item merge
1. Add "Simple Seasoned Rice" to a list (contains the complex butter ingredient)
2. Add a second recipe that also has butter

**Expected**: Butter entry shows yellow badge, quantity may not merge (unparseable), but recipe source is added
**Fail if**: App crashes or quantity shows nonsensical value

### Test 3.5: Consolidation button removed
1. Open any grocery list
2. Check the toolbar/navigation bar

**Expected**: No merge/consolidate button (arrow.triangle.merge icon) visible
**Fail if**: Consolidation button still appears

## Section 4: Edge Cases

### Test 4.1: Adding from grocery list directly
1. Open a grocery list
2. Tap **+** to add an item manually
3. Type "organic milk"
4. Save to templates when prompted

**Expected**: Ingredients tab shows "organic milk" (clean name)
**Fail if**: Quantity or other text leaks into template name

### Test 4.2: Duplicate manual add
1. On the same grocery list, tap **+** again
2. Type "organic milk" (same ingredient)

**Expected**: Existing template is found, no duplicate created
**Fail if**: A second "organic milk" template appears in Ingredients tab

### Test 4.3: Scaled recipe addition
1. Open a recipe with 4 servings
2. Change the serving count to 8 when adding to grocery list
3. Add the ingredients

**Expected**: All quantities are doubled (2x scale). E.g., if recipe has "1 cup butter", list shows "2 cup"
**Fail if**: Quantities are unscaled or scaled incorrectly
