# M10.6.15: Import Category Preservation + Polish

**Status**: COMPLETE
**Branch**: `feature/M10.6.15-import-category-preservation`
**Created**: March 4, 2026

## Problem

Device testing with the full import flow (AI parse → user categorization → manual edits → save → review) revealed that categories assigned during import preview are lost by the time the recipe is saved. Additional polish issues: truncated category picker, LLM not categorizing pantry items, parenthetical notes leaking into template names, and "Boxed & Canned" should be renamed "Pantry".

## Root Cause

`reMatchIngredient()` in `RecipeImportPreviewView.swift` calls `categoryAssignments.removeValue(forKey: index)` whenever a re-match returns nil category. User assigns category → edits ingredient text → re-match runs → no template found → category REMOVED. Same pattern in `EditRecipeView.commitIngredientEdit()`.

## Fixes

| 1 | Preserve category assignments on re-match (CRITICAL) | RecipeImportPreviewView.swift |
