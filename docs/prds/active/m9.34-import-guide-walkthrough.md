## Problem Statement

The recipe import preview is the most complex screen in the app — parsed ingredients, AI parsing, category assignment, split detection, alternative indicators, confidence dots. First-time users land here with no guidance on what any of it means.

The welcome walkthrough (M9.27) teaches the high-level flow (Import, Plan, Shop) but doesn't cover the import preview mechanics.

## Solution: Coach Mark Overlay on First Import

Reuse the existing `CoachMarkOverlay` system from `OnboardingView.swift`. Show it the first time the import preview appears.

### Trigger
- `@AppStorage("hasSeenImportGuide")` — false on first launch
- Shown when `RecipeImportPreviewView` appears and flag is false
- Set to true on completion or skip
- Replayable from Settings > "Replay Import Guide"

### Coach Mark Steps (5)

**Step 1: Title and Metadata**
- Spotlight: title area + metadata row
- "Review the recipe title and details. Tap anything to edit."

**Step 2: Ingredient Status**
- Spotlight: first ingredient row with status dots
- "Each ingredient is parsed and matched to your library. Green checkmark = matched. Amber circle = needs a category. Plus icon = new ingredient."

**Step 3: Smart Indicators**
- Spotlight: a split or alternative indicator row (if visible), or general ingredient area
- "Green 'Tap to split' rows detect multiple ingredients on one line. Amber rows flag alternatives where you should pick one. Both help keep your ingredient library clean."

**Step 4: AI Parse**
- Spotlight: "Parse with AI" sparkle button
- "Tap for AI-powered parsing that categorizes ingredients automatically. Long-press any ingredient for more options."

**Step 5: Save**
- Spotlight: Save button
- "Save to add this recipe and all ingredients to your library. They'll be available for meal planning and grocery lists."

### Settings Replay
- Add "Replay Import Guide" button in Settings About section
- Posts `NotificationCenter.default.post(name: .replayImportGuide)`
- RecipeImportPreviewView listens and shows overlay
