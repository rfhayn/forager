## Problem Statement

The recipe import preview is the most complex screen in the app — parsed ingredients, AI parsing, category assignment, split detection, confidence indicators. First-time users land here with no guidance on what the green dots mean, how to use the AI parse button, or that they can long-press ingredients for more options.

The welcome walkthrough (M9.27) teaches the high-level flow (Import → Plan → Shop) but doesn't cover the import preview mechanics. Users need contextual help at the moment they first encounter this screen.

## Solution: Coach Mark Overlay on First Import

Reuse the existing `CoachMarkOverlay` system from `OnboardingView.swift` — spotlights, arrows, glass cards, step progression. Show it the first time the import preview appears.

### Trigger
- `@AppStorage("hasSeenImportGuide")` — false on first launch
- Shown when `RecipeImportPreviewView` appears and flag is false
- Set to true on completion or skip
- Replayable from Settings > "Replay Import Guide"

### Coach Mark Steps (4)

**Step 1: Title & Metadata**
- Spotlight: title area + metadata row
- "Review the recipe title and details. Tap anything to edit."

**Step 2: Ingredient List**
- Spotlight: first ingredient row
- "Each ingredient is parsed and matched to your library. Green dot = matched. Amber = needs a category."

**Step 3: AI Features**
- Spotlight: sparkle button (batch parse) area
- "Tap the sparkle for AI-powered parsing. Long-press any ingredient for options like Split or re-parse."
- Mention the split badge: "Lines with a split icon may contain multiple ingredients."

**Step 4: Save**
- Spotlight: Save button area
- "When everything looks good, save. Ingredients are added to your library and available for future recipes and grocery lists."

### Settings Replay
- Add "Replay Import Guide" button in Settings > About section (next to "Replay Onboarding")
- Posts `NotificationCenter.default.post(name: .replayImportGuide)`
- `RecipeImportPreviewView` listens and shows overlay
