# M18.1.5: Store Assignment UI for Ingredients

## Problem

M18.1 added the Store entity, `StoreService`, and `IngredientTemplate.preferredStore` relationship. Users can create stores in Settings > Stores and group grocery items by store. But there's **no UI to assign a preferred store to ingredient templates** — the connection point between "I buy chicken at Costco" and the grocery list auto-grouping.

The existing `StoreAssignmentModal` (grocery list items) sets `preferredStore` on templates as a side effect, but there's no way to proactively assign stores to ingredients before they appear on a grocery list.

---

## Solution

### 1. Store Icon on Ingredient Rows (IngredientsView)

Add a storefront icon button to `IngredientRowView` alongside the existing category folder and staple pin buttons.

- **No store assigned**: storefront icon in `ForagerTheme.textTertiary`
- **Store assigned**: `StoreColorDot` + storefront icon in the store's color
- **Tap action**: opens `StoreChangeModal` for that single ingredient

### 2. "Needs Store" Banner (IngredientsView)

Add a banner at the top of IngredientsView (mirrors the existing "needs review" banner pattern) when ingredients lack a preferred store and stores exist.

```
[storefront icon] X ingredients need a store    [Assign Now]
```

- Only shows when `needsStoreCount > 0` AND user has created stores
- Uses `ForagerTheme.surfacePrimary` background (informational, not warning)
- "Assign Now" opens `StoreChangeModal` with all unassigned templates
- Allows walkthrough-style bulk assignment (like category assignment)

### 3. StoreChangeModal (New File)

Mirrors `CategoryChangeModal` pattern exactly:
- Header: "Assign Stores" + ingredient count
- ScrollView with per-ingredient rows, each showing current store status
- NavigationLink to store selection list with color dots
- "No Store" option
- "Assign Stores" + "Cancel" action buttons
- Summary footer: "X of Y assigned"

Uses `StoreService.assignStore(_:toTemplate:)` for persistence.

### 4. Grocery List "Group by Store" Toggle

The grocery list detail view already has "Group by Store" (M18.1.4, building icon in toolbar). Verify it works correctly with store-assigned templates. The toggle is gated behind `hasStores` which filters stores by `householdKey` — ensure stores created in Settings have the correct householdKey.
