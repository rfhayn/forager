# M15.6: Liquid Glass Polish & App Icon

## Context

M15.6 is the visual refinement phase — it applies iOS 26 Liquid Glass effects across all screens rebuilt in M15.3–M15.5, creates a layered app icon, evaluates glass button styling, and verifies the warm forest/cream palette reads correctly through glass material. This phase does NOT change layout or hierarchy — it adds glass effects and removes redundant shadows that glass replaces.

**Depends on**: M15.1 (TabView + ForagerTheme), M15.2 (all tokens migrated), M15.3 (ForagerCard, ForagerProgressRing, ForagerSectionHeader, CategoryChipPills, FilterPill, ForagerButtonStyles, grocery UX), M15.4 (RecipeCardView, timing pills, filter pills, hero header, scale pills), M15.5 (meal plan summary cards, day strip, ingredient filter pills, quickOption), M15.5b (Settings/Categories/Household visual redesign).

**What changes**: Glass effects on cards/floating elements/CTAs across all screens, shadow removal on glass-effected views, button glass styling evaluation, `GlassEffectContainer` grouping, layered app icon, glass+palette verification.

**What does NOT change**: Layout structure, data model, service layer, component logic. All structural work was completed in M15.3–M15.5.

**Key PRD reference**: §11 Liquid Glass API Reference, §4.4 Elevation & Shadows, §6.1–6.5 per-screen glass notes.

## Sub-Phase A: Glass Effect Helpers & Shadow Removal (1 hour)

### A.1: Add glass-aware ForagerCard variant

**File**: `forager/ForagerCard.swift` (MODIFY — created in M15.3)

The ForagerCard modifier from M15.3 uses explicit `.shadow()` (bark-tinted level 2). Glass elements create their own depth through refraction, so shadows must be removed when glass is applied.

Add a `.foragerGlassCard()` modifier variant:

```swift
struct ForagerGlassCardModifier: ViewModifier {
    func body(content: Content) -> some View {
        content
            .padding(ForagerTheme.Spacing.lg)
            .background(ForagerTheme.surfacePrimary)
            .clipShape(RoundedRectangle(cornerRadius: ForagerTheme.Radius.md, style: .continuous))
            .glassEffect(.regular, in: RoundedRectangle(cornerRadius: ForagerTheme.Radius.md, style: .continuous))
            // No shadow — glass provides depth through refraction
    }
}

extension View {
    func foragerGlassCard() -> some View {
        modifier(ForagerGlassCardModifier())
    }
}
```

**Design decision**: Keep both `.foragerCard()` (shadow-based) and `.foragerGlassCard()` (glass-based) during M15.6. Some contexts may not benefit from glass (e.g., compact inline elements). The audit in sub-phases B–D determines which views use which.

### A.2: Add prominent glass card variant

For hero elements and emphasized cards (recipe hero header, meal plan active card):

```swift
struct ForagerProminentGlassCardModifier: ViewModifier {
```


## Sub-Phase G: Layered Liquid Glass App Icon (1 hour)

### G.1: Current icon structure

The app currently has 3 flat PNG icon variants:
```
AppIcon.appiconset/
├── forager-icon-light.png    (1024×1024, default)
├── forager-icon-dark.png     (1024×1024, dark mode)
├── forager-icon-tinted.png   (1024×1024, tinted mode)
└── Contents.json
```

### G.2: Convert to layered icon format

iOS 26 Icon Composer creates multi-layer icons that respond to Liquid Glass effects (depth, specular highlights, parallax). The existing flat PNGs need to be decomposed into layers.

**Layer structure**:
1. **Background layer**: Warm cream-to-forest gradient
   - Light: `#F5F0E8` (cream) → `#2D5016` (forestGreen) diagonal gradient
   - Dark: `#1C1A14` (dark canvas) → `#0E1508` (nightForest) gradient
   - No sharp edges — soft radial or diagonal gradient
2. **Foreground layer**: Green sprout symbol (extracted from existing icon)
   - The forager sprout is the brand mark — keep it as the foreground element
   - White or light cream sprout on dark variant
   - Forest green sprout on light variant
3. **Glass specular layer**: Handled automatically by iOS 26 when using layered format

**Icon Composer workflow** (Xcode tool):
1. Open Xcode → File → New → Icon Composer document (`.icon` file)
2. Import background layer (gradient image, 1024×1024)
3. Import foreground layer (sprout with transparency, 1024×1024)
4. Preview all 6 appearance modes:
   - Default (light background + sprout)
   - Dark (dark background + light sprout)
   - Clear Light (glass-through on light wallpaper)
   - Clear Dark (glass-through on dark wallpaper)
   - Tinted Light (monotone light)
   - Tinted Dark (monotone dark)
5. Export and replace `AppIcon.appiconset` assets

### G.3: Update Contents.json for layered format

The Contents.json structure may need to change for layered icons. If Icon Composer exports an `.icon` file, the xcassets structure updates automatically. If manual:

```json
{
  "images" : [
    {
      "filename" : "icon_front.png",
      "idiom" : "universal",
      "layer" : "front",
      "platform" : "ios",
      "size" : "1024x1024"
    },
    {
      "filename" : "icon_back.png",
      "idiom" : "universal",
      "layer" : "back",
      "platform" : "ios",
      "size" : "1024x1024"
    }
  ],
  "info" : {
    "author" : "xcode",
    "version" : 1
  }
}
```

### G.4: Design guidelines for layers

Per PRD glass design guidelines:
- **Rounded corners**: Soft gradients, no sharp edges (light travels poorly through sharp geometry)
- **Sprout symbol**: Keep simple — avoid thin lines that disappear through glass refraction
- **Color contrast**: Sprout must be visible in ALL 6 appearance modes
- **Testing**: Preview on multiple wallpapers (light, dark, colorful) to ensure the glass-through modes look good

**Note**: The layered icon is a design asset task. If the existing sprout PNG isn't easily decomposable into layers, this may require graphic design work outside of code. The plan assumes the sprout can be extracted from the existing icon PNGs.

## Risk Analysis

| Risk | Severity | Mitigation |
|------|----------|------------|
| `.glassEffect()` API differs from assumption | Medium | Verify exact API signature in Xcode SDK autocomplete before applying. Fallback: skip glass, use existing shadow cards |
| `GlassEffectContainer` not available or different | Medium | Skip container grouping; individual glass effects still work |
| `.buttonStyle(.glass)` not available | Medium | Keep ForagerSecondaryButtonStyle with tint fill; no visual regression |
| Warm palette washed out through glass | High | Sub-phase H dedicated to verification. Adjust glass opacity or background tokens |
| Glass degrades 60fps performance | Medium | Profile with Instruments. Glass is GPU-composited but may spike on older A-series chips |
| Layered icon requires graphic design tools | Medium | If sprout can't be cleanly extracted, keep flat icon PNGs — functional, not blocked |
| Glass on dark mode makes text unreadable | High | Verify contrast in H.2. Adjust glass prominence or add background tint |
| Too many glass effects look cluttered | Medium | Less is more — during H.1/H.2, remove glass from elements where it adds noise not value |
