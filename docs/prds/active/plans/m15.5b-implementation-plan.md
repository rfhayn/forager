# M15.5b: Settings, Categories & Household Visual Redesign

## Context

M15.5b addresses a gap identified in the aggregate review: PRD §6.5 specifies significant visual redesigns for SettingsView, ManageCategoriesView, and a new dedicated HouseholdView that were not covered in any earlier plan. M15.1 elevated Settings to a dedicated 5th tab and added Data section links, and M15.2 migrated tokens, but the structural/visual redesign was missing.

**Depends on**: M15.1 (Settings tab exists), M15.2 (tokens migrated for SettingsView, ManageCategoriesView, HouseholdMembersView), M15.3 (ForagerCard, ForagerButtonStyles available), M15.5 (complete — no dependency on meal plan work, but sequenced after for branch clarity).

**What changes**: SettingsView grouped form styling with card-based navigation rows, ManageCategoriesView nav bar "+" button + lock icon + footer, new HouseholdView extracted from SettingsView with sync indicator + stats card + Invite button + Danger Zone.

**What does NOT change**: Data model, HouseholdService, CloudKit sync, invitation flow logic.

## Sub-Phase A: HouseholdView Extraction (1.5 hours)

### A.1: Create HouseholdView.swift

**File**: `forager/HouseholdView.swift` (NEW — pbxproj addition needed)

Extract household management from SettingsView into a dedicated push screen. Currently household content is inline in SettingsView (~100 lines of household sections + sheets).

**Layout per PRD §6.5**:

```swift
struct HouseholdView: View {
    @EnvironmentObject var householdService: HouseholdService

    var body: some View {
        Form {
            if let household = householdService.activeHousehold {
                // Header: Household name + edit pencil (owner only)
                householdHeader(household)

                // Members section
                membersSection(household)

                // Invite button
                inviteSection

                // Sharing stats
                sharingStatsSection(household)

                // Danger Zone
                dangerZoneSection(household)
            } else {
                noHouseholdSection
            }
        }
        .navigationTitle("Household")
        .navigationBarTitleDisplayMode(.large)
    }
}
```

### A.2: Household header with edit and sync indicator

**Important**: `householdService.isOwner(household:)` is an `async` method — it cannot be called directly in SwiftUI view body. Use `@State private var isOwner = false` loaded via `.task {}`:

```swift
@State private var isOwner = false

// In body or .task modifier:
.task {
    if let household = householdService.activeHousehold {
        isOwner = await householdService.isOwner(household: household)
    }
}

private func householdHeader(_ household: Household) -> some View {
    Section {
        HStack {
            if isEditing {
                TextField("Household Name", text: $editedName)
                    .font(ForagerTheme.cardTitle)
                    .onSubmit { saveHouseholdName() }
            } else {
                Text(household.name ?? "My Household")
                    .font(ForagerTheme.cardTitle)
                    .foregroundStyle(ForagerTheme.textPrimary)
            }

            Spacer()

            if isOwner {
                Button { isEditing.toggle() } label: {
                    Image(systemName: isEditing ? "checkmark" : "pencil")
                        .foregroundStyle(ForagerTheme.accentPrimary)
                }
            }
        }

        // Sync status indicator
        HStack(spacing: ForagerTheme.Spacing.sm) {
            Circle()
                .fill(ForagerTheme.statusSuccessFG)
                .frame(width: 8, height: 8)
            Text("Synced just now")
                .font(ForagerTheme.captionFont)
                .foregroundStyle(ForagerTheme.textTertiary)
        }
    }
}
```

### A.3: Members section with avatars and role badges

Integrate existing `HouseholdMembersView` content (248 lines) into HouseholdView as an inline section:

```swift
private func membersSection(_ household: Household) -> some View {
    Section("Members") {
        ForEach(members, id: \.self) { member in
            HStack {
                // Avatar: initials circle
                Text(initials(for: member))
                    .font(ForagerTheme.footnoteFont)
                    .foregroundStyle(.white)
                    .frame(width: 32, height: 32)
                    .background(ForagerTheme.accentSecondary)
                    .clipShape(Circle())

                VStack(alignment: .leading) {
                    Text(member.displayName ?? member.email ?? "Unknown")
                        .font(ForagerTheme.bodyFont)
                    if let joinedDate = member.joinedDate {
                        Text("Joined \(joinedDate, style: .date)")
                            .font(ForagerTheme.captionFont)
                            .foregroundStyle(ForagerTheme.textTertiary)
                    }
                }

                Spacer()

                // Role badge
                Text(member.role ?? "Member")
                    .font(ForagerTheme.captionFont)
                    .padding(.horizontal, ForagerTheme.Spacing.sm)
                    .padding(.vertical, 2)
                    .background(member.isOwner ? ForagerTheme.accentTint : ForagerTheme.backgroundSecondary)
                    .foregroundStyle(member.isOwner ? ForagerTheme.accentPrimary : ForagerTheme.textSecondary)
                    .clipShape(Capsule())
            }
            .swipeActions(edge: .trailing) {
                if isOwner && !member.isOwner {
                    Button(role: .destructive) { removeMember(member) } label: {
                        Label("Remove", systemImage: "person.badge.minus")
                    }
                }
            }
        }
    }
}
```

### A.5: Danger Zone

```swift
private func dangerZoneSection(_ household: Household) -> some View {
    Section {
        if isOwner {
            Button(role: .destructive) { showDeleteAlert = true } label: {
                Label("Delete Household", systemImage: "trash")
            }
        } else {
            Button(role: .destructive) { showLeaveAlert = true } label: {
                Label("Leave Household", systemImage: "rectangle.portrait.and.arrow.right")
            }
        }
    } header: {
        Text("Danger Zone")
    } footer: {
        Text(isOwner
            ? "Deleting removes all shared data for all members."
            : "Leaving removes your access to shared recipes, lists, and meal plans.")
            .font(ForagerTheme.captionFont)
    }
}
```

## Risk Analysis

| Risk | Severity | Mitigation |
|------|----------|------------|
| HouseholdView extraction breaks existing household flows | Medium | Keep all HouseholdService calls identical. Only UI layer changes. Test create/join/leave/share flows. |
| Sync status indicator accuracy | Low | Use simple "Synced just now" text initially. Can enhance with real-time CloudKitSyncMonitor in future. |
| Sharing stats query performance | Low | Simple count queries on shared store. Should be < 0.1s. |
| HouseholdMembersView becomes orphaned | Low | HouseholdView inlines the member list. HouseholdMembersView can be deleted or kept as utility. |
