# M15.2: Color & Typography Migration

## Context

M15.2 is the mechanical migration phase — replacing all hardcoded system colors, ad-hoc typography, and raw layout values with `ForagerTheme` tokens established in M15.1. This phase makes the app visually coherent with the warm forest/cream palette before M15.3–M15.5 do structural layout changes.

**What changes**: Hardcoded color references → ForagerTheme tokens, ad-hoc font calls → 8-size type scale, raw cornerRadius values → Radius tokens, 3 duplicate `categoryColor(for:)` → centralized method, `.foregroundColor()` → `.foregroundStyle()` (deprecated API cleanup).

**What does NOT change**: View hierarchy, layout structure, navigation flow, data model, service layer. Those are M15.3–M15.5.

**Depends on**: M15.1 complete (ForagerTheme.swift exists, Liquid Glass TabView active, CustomBottomNavigation.swift and HamburgerMenuView.swift deleted, foragerApp.swift button styles already migrated).

**IMPORTANT — Skipped files**: The following 6 files are **skipped** in M15.2 because M15.3–M15.5 structurally rewrite them with entirely new layout code. Token migration on these files would be wasted effort — M15.3–M15.5 use ForagerTheme tokens directly as they build:

| File | Rewritten In | Touch Points Skipped |
|------|-------------|---------------------|
| `RecipeListView.swift` | M15.4 | ~50 |
| `WeeklyListsView.swift` | M15.3 | ~10 |
| `GroceryListDetailView.swift` | M15.3 | ~25 |
| `MealPlanDetailView.swift` | M15.5 | ~30 |
| `MealPlanListView.swift` | M15.5 | ~4 |
| `IngredientsView.swift` | M15.5 | ~9 |

This saves ~128 touch points (~3-4 hours). The remaining ~646 touch points across ~31 files are still migrated in M15.2.

## Sub-Phase A: Mapping Tables & categoryColor Consolidation (1 hour)

### A.1: Color Mapping Reference

Every color replacement in M15.2 follows this table. Context determines which token to use — not every `.blue` maps to the same token.

| System Color | → ForagerTheme Token | When |
|---|---|---|
| `Color.blue` (CTA/action) | `ForagerTheme.accentPrimary` | Buttons, links, interactive controls |
| `Color.blue` (decorative) | `ForagerTheme.accentSecondary` | Icons, badges, non-interactive |
| `Color.blue` (info status) | `ForagerTheme.statusInfoFG` | Info banners, help text |
| `Color.red` (destructive) | `ForagerTheme.statusDangerFG` | Delete buttons, error text |
| `Color.red` (status) | `ForagerTheme.statusDangerFG` | Error indicators |
| `Color.green` (success) | `ForagerTheme.statusSuccessFG` | Check marks, success states |
| `Color.green` (category) | `ForagerTheme.categoryColor(for: "Produce")` | Category-specific |
| `Color.orange` (warning) | `ForagerTheme.statusWarningFG` | Warning states |
| `Color.gray` (text) | `ForagerTheme.textTertiary` | Metadata, secondary labels |
| `Color.gray` (background) | `ForagerTheme.backgroundSecondary` | Section backgrounds |
| `Color.gray` (border) | `ForagerTheme.borderDefault` | Dividers, outlines |
| `Color.purple` | `ForagerTheme.categoryColor(for: "Beverages")` | Category-specific |
| `Color.brown` | `ForagerTheme.categoryColor(for: "Pantry & Canned")` | Category-specific |
| `Color.cyan` | `ForagerTheme.categoryColor(for: "Frozen")` | Category-specific |
| `.primary` (text) | Keep as-is OR `ForagerTheme.textPrimary` | SwiftUI `.primary` adapts to dark mode — but ForagerTheme.textPrimary uses bark/cream, which is warmer |
| `.secondary` (text) | `ForagerTheme.textSecondary` | Metadata |
| `Color(.secondarySystemBackground)` | `ForagerTheme.backgroundSecondary` | Section backgrounds |
| `Color(.secondarySystemGroupedBackground)` | `ForagerTheme.backgroundSecondary` | Grouped content |
| `.white` (on accent bg) | Keep as-is | White-on-dark works in both modes |
| `.accentColor` | `ForagerTheme.accentPrimary` | System accent replacement |

### A.2: Typography Mapping Reference

| Current | → ForagerTheme Helper | Notes |
|---|---|---|
| `.font(.largeTitle)` | `ForagerTheme.screenTitle` | 34pt bold rounded |
| `.font(.title)` | `ForagerTheme.detailTitle` | 28pt bold rounded |
| `.font(.title2)` | `ForagerTheme.cardTitle` | 20pt semibold rounded (collapse from 22pt) |
| `.font(.title3)` | `ForagerTheme.cardTitle` | 20pt (collapse from 20pt — same) |
| `.font(.headline)` | `ForagerTheme.bodyFont.bold()` | 17pt bold — keep system design for body |
| `.font(.body)` | `ForagerTheme.bodyFont` | 17pt system (no change needed) |
| `.font(.subheadline)` | `ForagerTheme.secondaryFont` | 15pt system |
| `.font(.footnote)` | `ForagerTheme.footnoteFont` | 13pt semibold rounded |
| `.font(.caption)` | `ForagerTheme.captionFont` | 12pt semibold rounded |
| `.font(.caption2)` | `ForagerTheme.captionFont` | Collapse to 12pt |
| `.font(.system(size: 10))` | `ForagerTheme.tabLabel` | 10pt medium rounded |
| `.font(.system(size: 22))` | `ForagerTheme.cardTitle` | Collapse to 20pt |
| `.font(.system(size: 18))` | `ForagerTheme.bodyFont` | Collapse to 17pt |
| `.font(.system(size: 64))` | Keep as-is | Empty state icons — display size |

**Chrome vs. content rule**: Titles, headers, buttons, pills, labels, navigation → rounded. Body text, instructions, content → system (default).

### A.3: Corner Radius Mapping Reference

| Current | → ForagerTheme.Radius | Notes |

| `.cornerRadius(4)` | `.cornerRadius(ForagerTheme.Radius.xs)` | Chips, compact badges |
| `.cornerRadius(6)` | `.cornerRadius(ForagerTheme.Radius.sm)` | Round up to 8pt |
| `.cornerRadius(8)` | `.cornerRadius(ForagerTheme.Radius.sm)` | Buttons, pills |
| `.cornerRadius(10)` | `.cornerRadius(ForagerTheme.Radius.md)` | Round to 12pt |

| `.cornerRadius(16)` | `.cornerRadius(ForagerTheme.Radius.lg)` | Sheets, large cards |

## Risk Analysis

| Risk | Severity | Mitigation |
|---|---|---|
| Context-dependent color mapping causes wrong token choice | High | Review each `.blue` in context — CTA vs decorative vs status. Don't blind-replace. |
| `.foregroundStyle()` behaves differently from `.foregroundColor()` in some contexts | Medium | `.foregroundStyle()` applies hierarchically to child views. Test each change. If issues arise, keep `.foregroundColor()` for that specific case. |
| Rounded typography looks wrong on body text | Low | Only apply rounded to chrome (titles, headers, buttons, pills). Body text stays system default. |
| Font size collapse (22→20, 18→17) causes layout shifts | Medium | Build-check after each file group. Adjust padding if needed. |
| Category colors don't match PRD in dark mode | Medium | PRD §4.1.8 specifies both light and dark hex values. ForagerTheme asset catalog has both. Verify in simulator. |
| Debug views reference removed colors | Low | Debug views are developer-only. Fix or skip as needed. |
| `categoryEmoji(for:)` functions still referenced after removing emojis | Medium | Search for all callers before deleting. If referenced, leave the function but remove emoji content (return empty string or SF Symbol name). |
