# M15.1: Design System Foundation & Liquid Glass TabView

## Context

M15 is a 7-phase UX overhaul of the forager iOS app. M15.1 is the foundation phase that creates the design token system and replaces the custom navigation with iOS 26 Liquid Glass TabView. Every subsequent M15 phase depends on the tokens and tab structure established here.

**Why now**: Design phase is complete (PRD v1.1, 16 HTML mockups, 5-phase design review). TestFlight is live. M15 was elevated to pre-launch priority — polished UI before App Store debut.

**What changes**: Deployment target (18→26), navigation (custom→Liquid Glass TabView), design tokens (none→38 semantic colors + typography + spacing). **What does NOT change**: Data model, service layer, CloudKit sync, parsing engine.

## Sub-Phase C: Replace Navigation with Liquid Glass TabView (2-2.5 hours)

### C.1: Rewrite foragerApp.swift body

Replace `CustomBottomNavigationView` (line 71) with native TabView:

```swift
ZStack {
    TabView(selection: $selectedTab) {
        Tab("Lists", systemImage: "list.bullet", value: .lists) {
            NavigationStack { WeeklyListsView(popToRoot: $listsPopToRoot) }
        }
        Tab("Recipes", systemImage: "book", value: .recipes) {
            NavigationStack { RecipeListView(popToRoot: $recipesPopToRoot) }
        }
        Tab("Meals", systemImage: "calendar", value: .mealPlans) {
            NavigationStack { MealPlansListView(popToRoot: $mealPlansPopToRoot) }
        }
        Tab("Settings", systemImage: "gearshape", value: .settings) {
            NavigationStack { SettingsView() }
        }
        Tab("Search", systemImage: "magnifyingglass", value: .search) {
            NavigationStack { UnifiedSearchView() }
        }
    }

    if showCoachMarks {
        CoachMarkOverlay(isActive: $showCoachMarks, selectedTab: $selectedTab)
    }
}
```

**Note**: `Tab(role: .search)` causes type mismatch with `TabView(selection:)` — use standard `Tab("Search", systemImage:, value:)` instead. Can explore `Tab(role: .search)` in M15.6 if API supports it.

**State to add**: `@State private var listsPopToRoot`, `recipesPopToRoot`, `mealPlansPopToRoot` (moved from CustomBottomNavigationView)

**Preserve all existing modifiers**: `.environment()`, `.environmentObject()`, `.task{}`, `.onAppear{}`, `.onReceive()` — move from `CustomBottomNavigationView` to the `TabView`.
