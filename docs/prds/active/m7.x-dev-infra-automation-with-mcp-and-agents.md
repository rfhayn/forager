## Executive Summary

- Git workflows (branch creation, commits, PRs, merges)
- Documentation updates (5 files per phase)
- Session startup procedures (8-point mandatory checklist)
- CloudKit debugging (error research and solutions)
- Test validation (result tracking and progress monitoring)

### Technology Stack

**MCP Servers** (Model Context Protocol):
- GitHub MCP: Git operations via GitHub API
- Brave Search MCP: Web search via Brave Search API
- Filesystem MCP: Local file operations (built-in)

**AI Agents** (Claude Projects):
- Session Startup Agent: Auto-loads project context
- Documentation Agent: Updates 5 files per phase
- CloudKit Validation Agent: Tracks test results

**Infrastructure**:
- Node.js 18+: Runtime for MCP servers
- Claude Desktop: Primary interface
- Claude Code: CLI interface (optional)
- Claude Projects: Cloud-synced agent instructions

### Component Details

| Component | Type | Setup Location | Sync Behavior | Purpose |
|-----------|------|----------------|---------------|---------|
| **GitHub MCP** | Per-computer | Local config | None | Automate git workflow |
| **Brave Search MCP** | Per-computer | Local config | None | Accelerate debugging |
| **Filesystem MCP** | Built-in | None | None | File operations |
| **Session Startup Agent** | Cloud | Claude Projects | Auto-sync | Auto-load context |
| **Documentation Agent** | Per-computer | Local file | Manual sync | Update 5 docs |
| **CloudKit Validation** | Cloud | Claude Projects | Auto-sync | Track tests |

### Data Flow

**Typical Phase Completion Flow**:
```
1. Developer completes implementation in Xcode
   ↓
2. Reports results to Claude Desktop (Forager Project)
   ↓
3. CloudKit Validation Agent (if testing)
   - Validates test results
   - Tracks progress (X/N tests)
   - Calculates metrics
   ↓
4. Documentation Agent (phase complete)
   - Parses completion data
   - Updates 5 files via Filesystem MCP
   - Generates git commit message
   ↓
5. GitHub MCP (git workflow)
   - Commits with proper M#.#.# message
   - Pushes to origin
   - Creates PR
   - Squash merges to main
   ↓
6. Developer reviews and approves
   - Total time: 2-3 minutes (vs 30 minutes manual)
```

### Security Considerations

**GitHub Personal Access Token**:
- Stored locally in Claude Desktop config
- Never transmitted to Anthropic servers
- Scopes limited to: repo, workflow, read:org
- Can be revoked anytime at github.com/settings/tokens

**Brave Search API Key**:
- Stored locally in Claude Desktop config
- Free tier: 2,000 queries/month
- No sensitive data transmitted

**Filesystem Access**:
- Claude Desktop has read/write to Documents folder
- No external transmission of code/docs
- Governed by macOS permissions

**Claude Projects**:
- Project knowledge stored on Anthropic servers
- Does not include code or sensitive data
- Only documentation and instructions
- Syncs across devices via Anthropic account

#### Step 1.1: GitHub MCP Server (30 min)

**Tasks**:

**1. Create GitHub Personal Access Token** (5 min)
```bash
# Open in browser
open https://github.com/settings/tokens/new

# Configure:
Note: "Claude MCP for Forager"
Expiration: 1 year (or No expiration)
Scopes:
  ✅ repo (Full control of private repositories)
  ✅ workflow (Update GitHub Action workflows)
  ✅ read:org (Read org and team membership)

# Click "Generate token"
# IMMEDIATELY SAVE to 1Password: "GitHub MCP Token"
# Format: ghp_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

**2. Install GitHub MCP Server** (5 min)
```bash
# Install globally
npm install -g @modelcontextprotocol/server-github

# Verify installation
which mcp-server-github
# Expected output: /usr/local/bin/mcp-server-github or similar

# If command not found, check npm global path:
npm config get prefix
```

```bash
      "env": {
        "GITHUB_PERSONAL_ACCESS_TOKEN": "ghp_PASTE_YOUR_TOKEN_HERE"

}
```
