## S1 Overview

### 1.1 Problem Statement

When a user imports a recipe, uncategorized ingredients trigger the `CategoryAssignmentModal`. Currently this shows all ingredients at once with "Choose Category" pickers — but the user can't edit ingredient names to fix OCR/extraction errors, and the NavigationLink-based category picker is clunky.

The Ingredients tab already has an excellent **review sheet** (`IngredientReviewSheet`, lines 900-1148 of `IngredientsView.swift`) that handles this exact workflow: step through ingredients one at a time, edit name, pick category, save & advance. We should reuse this proven pattern.

### 1.2 Solution

Replace the current `CategoryAssignmentModal` list-of-all-ingredients layout with the `IngredientReviewSheet` card-by-card pattern:
- Progress bar with "1 of N" counter
- Editable name TextField
- Category picker (Menu dropdown — not NavigationLink)
- "Skip" and "Save & Next" buttons
- On name edit + save: rerun parsing → template matching → auto-assign category if match found

### 1.3 Design Principles

- **Mirror existing pattern** — reuse the `IngredientReviewSheet` UI pattern exactly
- **Edit triggers re-match** — editing a name reruns `parseIngredient()` + `searchTemplates()` to find existing categorized templates
- **LLM-ready** — category prediction deferred to M10.6; for now, manual pick or auto-match on edit
- **Shared component** — `CategoryAssignmentModal` is used by both import and grocery list flows; changes work for both

## S3 Implementation

### What to Change

**Replace `CategoryAssignmentModal` internals** with the review sheet pattern. Keep the same struct name and `onAssignmentsComplete` callback so callers don't change.

**Modified file**: `forager/Views/Grocery/CategoryAssignmentModal.swift`

**Changes:**

1. **Replace list layout with card-by-card stepper:**
   - Remove `IngredientAssignmentRow` (the per-row view)
   - Remove `categoryAssignments: [UUID: String?]` dictionary
   - Add `@State private var currentIndex = 0`
   - Add `@State private var editedName = ""`
   - Add `@State private var selectedCategory: String = ""`
   - Add `loadCurrentIngredient()` / `saveAndAdvance()` / `advance()` methods

2. **Add ingredient card** (mirror `IngredientReviewSheet.ingredientCard`):
   - Editable name TextField
   - Category Menu picker (from existing `allCategories` fetch)
   - Progress bar + "N of M" counter
   - "Skip" + "Save & Next" buttons

3. **On name edit save — rerun matching:**
   - `parsingService.parseIngredient(text: editedName)` → clean `displayName`
   - `templateService.searchTemplates(query: displayName, limit: 5)` → look for exact match
   - If match found with category → auto-fill `selectedCategory`
   - If match found without category → name corrected but still needs category
   - If no match → update template name, manual category pick

4. **On last ingredient:** call `onAssignmentsComplete()` (same as current flow)

5. **Remove sub-views that are no longer needed:**
   - `IngredientAssignmentRow`
   - `CategorySelectionViewForAssignment`
   - `CategorySelectionRowForAssignment`
   - `addNewCategoryButton` (categories can be added from Settings; not needed inline)

### Environment Objects Needed

Both already injected at app root:
- `@EnvironmentObject private var ingredientTemplateService: IngredientTemplateService` (already present)
- `@EnvironmentObject private var parsingService: IngredientParsingService` (add)

### Merge-on-Rename Logic

If the user edits a name and it matches an existing template, follow the same merge logic as `IngredientRowView.saveNameEdit()` (lines 781-885):
- If exact match exists → merge (move ingredient relationships, sum usage counts, delete old template)
- If no match → just rename via `updateTemplate()`

## S4 Data Flow

```
CategoryAssignmentModal opens with N uncategorized templates
  │
  ├─ loadCurrentIngredient() → populate editedName, selectedCategory from template[0]
  │
  ├─ User sees card with editable name + category picker
  │
  ├─ User edits name "garlik powdr" → "garlic powder"
  │   ├─ parseIngredient("garlic powder") → displayName: "Garlic Powder"
  │   ├─ searchTemplates("Garlic Powder")
  │   │   ├─ MATCH with category "Spices" → auto-fill selectedCategory = "Spices"
  │   │   └─ NO MATCH → selectedCategory unchanged, user picks manually
  │   └─ (match logic runs on Save & Next, not on every keystroke)
  │
  ├─ User taps "Save & Next"
  │   ├─ updateTemplate(template, name: editedName, category: selectedCategory)
  │   ├─ advance() → currentIndex += 1, loadCurrentIngredient()
  │   └─ If last → onAssignmentsComplete()
  │
  └─ User taps "Skip"
      ├─ template.category = "Uncategorized" (or leave nil)
      ├─ advance()
      └─ If last → onAssignmentsComplete()
```
