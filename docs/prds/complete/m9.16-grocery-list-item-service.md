# M9.16: Unified GroceryListItemService & Meal Plan Ingredient Selection

**Status**: ACTIVE
**Estimated**: 8-12 hours (Complex)
**Dependencies**: M9.15 (householdKey on Ingredient/GroceryListItem)

## 1. Problem

### 1.1 Fragmented Item Creation

Six separate code paths create `GroceryListItem` objects with inconsistent behavior:

| Path | File | Template | Category | Cross-Store | Merge | Scaling |
|------|------|:---:|:---:|:---:|:---:|:---:|
| Recipe → List | AddIngredientsToListView | Yes | Yes | Yes | Yes | Yes |
| Manual Entry | AddListItemView | Yes | Yes (picker) | No | No | No |
| Quick-Add | GroceryListDetailView | Yes | Yes (template) | No | No | No |
| Meal Plan Generate | MealPlanService | Yes (fallback) | Yes | Yes | No | No |
| Staples | WeeklyListsView | direct | Yes (template) | No | No | No |
| Bulk Meal Plan | MealPlanDetailView | partial | No | No | No | Yes |

Bugs we've fixed independently in multiple paths:
- Items showing as "Uncategorized" (fixed in paths 1, 4; path 6 still broken)
- Cross-store category assignment crashes
- Template re-lookup creating new uncategorized templates
- Missing householdKey on created items

### 1.2 No Ingredient Selection for Meal Plans

Current meal plan -> grocery list flow auto-adds ALL ingredients from ALL recipes. The user has no ability to:
- Deselect ingredients they already have
- Review what's being added per recipe
- Assign categories to uncategorized items before adding

## 2. Solution: GroceryListItemService

A single service that ALL creation paths call. Consolidates the full pipeline:

```
Input (name, quantity, template, recipe)
  -> Clean name extraction
  -> Template resolution (findOrCreate)
  -> Category resolution (template -> category)
  -> Cross-store safety check
  -> Merge with existing list items (optional)
  -> GroceryListItem creation
  -> householdKey inheritance from parent WeeklyList
```

### 2.1 Service API

```swift
@MainActor
class GroceryListItemService: ObservableObject {
    func addItem(to:name:cleanName:structured:existingTemplate:scaleFactor:sourceRecipe:source:mergeWithExisting:) -> GroceryListItem?
    func addIngredients(_:to:scaleFactor:sourceRecipe:mergeWithExisting:) -> [GroceryListItem]
    func addStaples(_:to:) -> [GroceryListItem]
    func resolveCategory(for:targetList:) -> Category?
    func findUncategorizedTemplates(for:) -> [IngredientTemplate]
}
```

### 2.2 Internal Pipeline (addItem)

1. Clean name: `cleanName ?? IngredientParsingService.extractCleanIngredientName(from: name)`
2. Structured quantity: `structured ?? parsingService.parseToStructured(text: name)`
3. Template: `existingTemplate ?? templateService.findOrCreateTemplate(name: cleanName)`
4. Category: `resolveCategory(for: template, targetList: list)` (cross-store safe)
5. Scale: Apply `scaleFactor` to `structured.numericValue` if parseable
6. Merge check: If `mergeWithExisting`, find existing uncompleted item with same normalized name -> delegate to `GroceryMergeService.merge()` -> update existing and return it
7. Create: `GroceryListItem(context:)` with all fields, `household`/`householdKey` from parent WeeklyList
8. Save: `context.save()` (batched for multi-item adds)

## 3. Meal Plan Ingredient Selection

**Option A: Recipe-by-Recipe Wizard** (chosen for initial implementation)

Flow: Tap "Add to Grocery List" -> wizard cycles through each recipe. For each, show ingredient selection UI (checkboxes, servings stepper). After last recipe, pick target list and add.

"Add All Remaining" button on every screen as escape hatch.
