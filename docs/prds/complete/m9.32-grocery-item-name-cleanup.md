# M9.32: Grocery Item Name Cleanup — Clean Names for Aggregation

**Status**: PLANNED
**Estimated**: 1-2 hours
**Priority**: High (user-visible data quality issue)
**Last Updated**: March 23, 2026

---

## Problem Statement

When ingredients are added to the shopping list from recipes, the raw ingredient text is stored including qualifiers, preparation instructions, and recipe-specific notes.

Examples from real usage:

- "boneless skinless antibiotic free chicken breasts, pounded to even thickness" should be "4 chicken breasts"
- "ground beef, (80/20 fat percentage)" and "lean ground beef" should merge as "ground beef"
- "Freshly grated Parmesan, for serving" should be "Parmesan"

Impact: Same ingredient from different recipes appears as separate items (no merge). Shopping list is cluttered with prep instructions not relevant while shopping.

## Root Cause

GroceryListItemService.addItem() stores raw ingredient text on GroceryListItem.name. The clean name IS extracted earlier in the same function but not used for the stored name. The template canonicalName exists but is never propagated.

## Solution

### Phase 1: Clean Name at Creation (1h)

In GroceryListItemService.addItem(), replace raw text with formatted clean name:
- Build display: "{qty} {cleanName}" (e.g., "2 cups ground beef")
- Use resolvedCleanName (already extracted) instead of raw name
- Same change in addIngredients() batch path

### Phase 2: Improve Merge Matching (0.5h)

In findExistingItem(), add template-based matching as primary path:
- Primary: match by template canonicalName (most reliable)
- Fallback: normalized text matching (current logic)

### Phase 3: Handle Existing Data (0.25h)

Existing dirty items stay as-is. New items will be clean. Merge logic uses template canonical name so new clean items can match old dirty ones.

## Files Modified

- Services/GroceryListItemService.swift (addItem name formatting, findExistingItem matching)
- No schema changes needed

## Acceptance Criteria

- Import recipe with qualifier-laden chicken breasts then grocery item shows clean "4 chicken breasts"
- Import second recipe with different chicken breasts qualifiers then merges with existing
- "ground beef (80/20)" and "lean ground beef" become single "ground beef" item
- Prep instructions stripped from shopping list names
- Build succeeds with zero warnings
