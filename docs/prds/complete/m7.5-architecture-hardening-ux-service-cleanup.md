## Executive Summary

M7.5 centralizes Core Data write paths into services, converts the 3 highest-complexity views to enum-based navigation, and adds automated tests for data integrity. This milestone focuses on **code clarity, testability, and forward-compatibility with M8.4 ML parsing**.

**Why Now:**
- **Service Ownership**: Clear write paths make debugging easier and enable parser DI for M8.4
- **Navigation Predictability**: Enum routing on the 3 worst offenders eliminates boolean state bugs
- **Testability**: Service unit tests + integration tests become M8.4 regression safety net
- **Forward-Compatible**: Services accept `IngredientParsingService` via init — M9.5-partial DI flows through without re-touching services

**Key Deliverables:**
- Service-owned save pattern (all writes go through services)
- Enum-based navigation routing (3 highest-complexity views)
- 18-22 automated tests across 5 test files (service, integration, invariant)

**What M15 Already Accomplished:**
- Empty state standardization (`ContentUnavailableView` on 5 views, `StandardEmptyStateView` deleted)
- Member count refresh bug fixed (M15.5b HouseholdView extraction)
- SettingsView decomposition (867 → 549 lines, HouseholdView extracted)
- Native Liquid Glass TabView (replaced CustomBottomNavigation)

**Tests:**

```swift
import XCTest
import CoreData
@testable import forager

/// M7.5 Phase 3.2: Core Data Invariant Tests
/// Validates critical data integrity rules that must never be violated
/// Pattern: In-memory testing following existing MigrationValidationTests approach
final class CoreDataInvariantsTests: XCTestCase {

    var persistence: PersistenceController!
    var context: NSManagedObjectContext!

    override func setUp() {
        super.setUp()
        persistence = PersistenceController(inMemory: true)
        context = persistence.container.viewContext
    }

    override func tearDown() {
        context = nil
        persistence = nil
        super.tearDown()
    }

    // MARK: - Seeding Invariants

    /// Test 1: Default seeding is idempotent
    func testDefaultSeedingIdempotency() throws {
        try DefaultSeeder.seedDefaultsIfNeeded(in: context)
        let firstCount = try context.count(for: Category.fetchRequest())

        try DefaultSeeder.seedDefaultsIfNeeded(in: context)
        let secondCount = try context.count(for: Category.fetchRequest())

        XCTAssertEqual(firstCount, secondCount, "Seeding should be idempotent")
        XCTAssertGreaterThan(firstCount, 0, "Should have default categories")
    }

    // MARK: - Template Invariants

    /// Test 2: IngredientTemplate uses `name` (not `displayName`)
    func testIngredientTemplateUsesNameProperty() throws {
        let template = IngredientTemplate(context: context)
        template.id = UUID()
        template.name = "Basil"
        try context.save()

        let request: NSFetchRequest<IngredientTemplate> = IngredientTemplate.fetchRequest()
        request.predicate = NSPredicate(format: "name == %@", "Basil")
        let results = try context.fetch(request)
        XCTAssertEqual(results.count, 1, "Should find template by name property")
        XCTAssertEqual(results.first?.name, "Basil")
    }

    // MARK: - Cascade Delete Invariants
```
