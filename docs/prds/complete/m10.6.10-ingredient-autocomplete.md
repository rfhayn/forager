# M10.6.10: Ingredient Template Autocomplete + Visual Match Distinction

**Status**: ACTIVE
**Created**: 2026-03-03
**Milestone**: M10.6.10
**Branch**: `feature/M10.6.7-household-api-key` (continuation)

## Problem Statement

When ingredients are saved (manual entry, URL import, text paste, photo), each ingredient is matched against existing IngredientTemplate entries. **Matched** ingredients link to the existing template; **unmatched** ingredients need autocomplete/search so the user can find the right template or create a new one. The rule: every ingredient MUST be in the ingredient list (IngredientTemplate table).

Currently:
- **CreateRecipeView** has autocomplete (reference implementation) — `IngredientAutocompleteService` with 4-pass search + dropdown
- **RecipeDetailView** has tap-to-edit but **no autocomplete** — edits re-parse locally only
- **RecipeImportPreviewView** has tap-to-edit but **no autocomplete** — same issue
- **IngredientMatchRow** status icon doesn't distinguish `.needsTemplate` from `.needsCategory`
- The `+ Add Ingredient` field in RecipeDetailView has no autocomplete

## Solution

1. Update `IngredientMatchRow` status icon to three distinct visual states
2. Add autocomplete to `RecipeDetailView` ingredient editing and `+ Add Ingredient`
3. Add autocomplete to `RecipeImportPreviewView` ingredient editing

## Detailed Design

### Step 1: Three-State Status Icon

**File**: `forager/Components/IngredientMatchRow.swift`

| Status | Icon | Color | Meaning |
|--------|------|-------|---------|
| `.ready` | `checkmark.circle.fill` | `statusSuccessFG` (green) | Template matched + has category |
| `.needsCategory` | `circle.dashed` | `statusWarningFG` (amber) | Template matched, needs category |
| `.needsTemplate` | `plus.circle` | `textTertiary` (gray) | No template match — new ingredient |

Add "NEW" badge text for `.needsTemplate` status. Update `IngredientMatchSummaryView` to show three counts.

### Step 2: Autocomplete in RecipeDetailView

**File**: `forager/Views/Recipes/RecipeListView.swift`

- Add `IngredientAutocompleteService` as `@StateObject`
- Wire `debouncedSearch()` into ingredient edit `TextField` via `.onChange(of:)`
- Show autocomplete dropdown after editing row when suggestions available
- Add `selectAutocompleteForEdit()` method (rebuilds text with template name)
- Wire autocomplete into `addIngredientField` as well

### Step 3: Autocomplete in RecipeImportPreviewView

**File**: `forager/Views/Import/RecipeImportPreviewView.swift`

Same pattern as Step 2:
- Add `IngredientAutocompleteService` as `@StateObject`
- Wire into ingredient editing via `.onChange(of:)`
- Show dropdown, add `selectAutocompleteForImport()` method
- Update match result and category assignment on selection

### Step 4: IngredientAutocompleteService Enhancement

**File**: `Services/IngredientAutocompleteService.swift`

Add `clearSuggestions()` method called when editing is dismissed or template is selected.
