# M15.5: Meal Plans & Ingredients UX

## Context

M15.5 handles two screen groups that share structural patterns: meal plan overview/detail and the ingredients library. Meal plans get weekly summary cards with lettered day-initial circles, a "Tonight" snippet, and inline recipe pickers for unplanned days. Ingredients get individual category filter pills, centered section headers, and a guided review sheet.

**Depends on**: M15.1 (ForagerTheme, TabView), M15.2 (tokens migrated), M15.3 (ForagerCard, ForagerSectionHeader, ForagerProgressRing, CategoryChipPills, FlowLayout — all available), M15.4 (RecipeCardView timing pills pattern, filter pill pattern).

**What changes**: MealPlansListView (flat → summary cards with day dots + "Tonight" + "Generate Grocery List"), MealPlanDetailView (vertical list → horizontal day strip with today highlight, inline recipe picker, quick-select pills, action buttons), IngredientsView (dropdown filter → individual category pills, sort moved to toolbar, centered section headers, review banner + sheet).

**What does NOT change**: Data model, MealPlanService, IngredientParsingService, IngredientTemplateService, PlannedMeal entity.

## Sub-Phase A: MealPlansListView — Weekly Summary Cards (2 hours)

### A.1: Lettered day-initial circles

PRD §6.3: 22pt circles with day-of-week initial (M, T, W, T, F, S, S). Filled `accentPrimary` + white text for planned days, outlined with `borderDefault` for unplanned.

```swift
struct DayDotsRow: View {
    let mealPlan: MealPlan
    let plannedDates: Set<Date>

    private let dayInitials = ["M", "T", "W", "T", "F", "S", "S"]

    var body: some View {
        HStack(spacing: ForagerTheme.Spacing.sm) {
            ForEach(Array(daysInPlan.enumerated()), id: \.offset) { index, date in
                let isPlanned = plannedDates.contains(where: { Calendar.current.isDate($0, inSameDayAs: date) })

                Text(dayInitials[Calendar.current.component(.weekday, from: date) - 1])
                    .font(ForagerTheme.captionFont)
                    .foregroundStyle(isPlanned ? .white : ForagerTheme.textTertiary)
                    .frame(width: 22, height: 22)
                    .background(
                        Circle()
                            .fill(isPlanned ? ForagerTheme.accentPrimary : .clear)
                    )
                    .overlay(
                        Circle()
                            .strokeBorder(isPlanned ? .clear : ForagerTheme.borderDefault, lineWidth: 1)
                    )
            }
        }
    }

    private var daysInPlan: [Date] {
        guard let start = mealPlan.startDate else { return [] }
        return (0..<Int(mealPlan.duration)).compactMap {
            Calendar.current.date(byAdding: .day, value: $0, to: start)
        }
    }
}
```

**Day initial mapping**: Use `Calendar.current.component(.weekday)` → map Sunday(1)=S, Monday(2)=M, etc. Not hardcoded M-T-W-T-F-S-S since plan may start on any day.
