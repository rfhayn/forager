## Problem Statement

### Research Findings

External review (ChatGPT and Gemini) independently identified that:

1. **CloudKit handles most error cases automatically** - NSPersistentCloudKitContainer queues operations offline, retries transient failures, and handles conflicts
2. **Current error handling is materially solid** - HouseholdError enum, graceful degradation, and sync state tracking are already in place
3. **BUT there are architecture risks** that matter more than error UI polish

### Architecture Risks Identified

**Risk 1: Ghost Data Bug (P0 - Must Fix)**

In `HouseholdService.loadCurrentHousehold()` (~line 202), there's a logic flaw:

```swift
if hasLeftHousehold(householdID) {
    let isParticipant = await isCurrentUserParticipant(in: household)
    if isParticipant {
        // BUG: Assumes user re-joined, clears the "left" flag
        clearLeftHouseholdFlag(householdID)
        // User is now back in household they tried to leave!
    }
}
```

**The Problem**: If server-side leave fails but local cleanup succeeds:
1. User thinks they left the household
2. `hasLeftHousehold()` returns true
3. But `isCurrentUserParticipant()` also returns true (server leave failed)
4. Code assumes "user re-joined" → clears flag → user is back in household

This creates a "ghost rejoin" where users appear back in households they tried to leave.

**Risk 2: exit(0) Anti-Pattern (P0 - Must Fix)**

In `AcceptInvitationSheet.swift` (~line 117), after 30-second timeout:

```swift
.alert("Restart Required", isPresented: $showRestartAlert) {
    Button("Restart App", role: .destructive) {
        exit(0)  // Apple explicitly discourages this
    }
}
```

**The Problem**:
- Apple discourages exit(0) as it looks like a crash to users
- On slow networks, sync might succeed 2 seconds after timeout
- User has no way to retry without force-closing app

**Risk 3: Duplicate Error Mapping (P1 - Technical Debt)**

Two places map CKError codes:
- `CloudKitSyncMonitor.mapCloudKitError()` - 8 cases with magic numbers
- `CloudKitDiagnostics.cloudKitErrorMessage()` - 6 cases

Different messages, different implied behavior. Creates UX confusion in beta.

**Risk 4: No Logging (P1 - Critical for Beta)**

All CloudKit debugging uses `print()`. When beta testers report "it didn't work":
- Can't retrieve logs from TestFlight devices
- Can't see what actually happened
- Will be guessing instead of debugging

## Technical Specifications

### ERR-001: Ghost Data Bug Fix

**Location**: `Services/HouseholdService.swift`, `loadCurrentHousehold()` method (~line 202)

**Current (Buggy) Logic**:
```swift
if let householdID = household.id?.uuidString, hasLeftHousehold(householdID) {
    let isParticipant = await isCurrentUserParticipant(in: household)
    if isParticipant {
        // WRONG: Assumes re-join, clears flag
        print("🔄 Household... was left but user has re-joined — clearing flag")
        clearLeftHouseholdFlag(householdID)
        // ... proceeds to set currentHousehold
    }
}
```

**Fixed Logic**:
```swift
if let householdID = household.id?.uuidString, hasLeftHousehold(householdID) {
    let isParticipant = await isCurrentUserParticipant(in: household)
    if isParticipant {
        // M7.3.4: Don't auto-clear flag. User must explicitly re-join via new invitation.
        // This prevents "ghost rejoin" when server-side leave failed.
        print("⚠️ M7.3.4: User marked as left but still participant - ignoring household")
        print("   (User must accept new invitation to rejoin)")
        continue  // Skip this household, don't put user back in
    }
}
```

**When Flag Gets Cleared**: Only in `checkForAcceptedInvitations()` when user explicitly accepts a new invitation. This path already exists—we just need to NOT auto-clear in `loadCurrentHousehold()`.

**Edge Case Handling**:
- If user genuinely re-joined via new invitation, the flag is cleared in `checkForAcceptedInvitations()`
- If server-side leave failed, user stays "out" of household until they explicitly rejoin
- Local data was already cleaned up, so there's no stale data issue

### ERR-002: Replace exit(0) with Check Again

**Location**: `forager/AcceptInvitationSheet.swift` (~line 117-126)

**Current Code**:
```swift
.alert("Restart Required", isPresented: $showRestartAlert) {
    Button("Restart App", role: .destructive) {
        exit(0)
    }
    Button("Cancel", role: .cancel) { dismiss() }
} message: {
    Text("The household data hasn't synced yet. Please restart the app to complete setup.")
}
```

**Fixed Code**:
```swift
// Rename state variable for clarity
@State private var showRetryAlert = false

// ...

.alert("Still Syncing", isPresented: $showRetryAlert) {
    Button("Check Again") {
        Task { await retryCheck() }
    }
    Button("Cancel", role: .cancel) { dismiss() }
} message: {
    Text("The household data is still syncing from iCloud. This can take longer on slow networks. Tap 'Check Again' to retry.")
}

// Add retry method
private func retryCheck() async {
    // Show loading state
    isChecking = true
    defer { isChecking = false }

    await service.checkForAcceptedInvitations()

    if let _ = service.currentHousehold {
        // Success! Dismiss the sheet
        dismiss()
    } else {
        // Still not synced, show alert again
        showRetryAlert = true
    }
}
```

**Additional State**:
```swift
@State private var isChecking = false  // For loading indicator on Check Again
```

**UX Improvements**:
- No exit(0) - app stays running
- User stays in control
- Works on slow networks (unlimited retries)
- Clear messaging about what's happening

### ERR-010: CloudKitErrorMapper Utility

**New File**: `Services/Persistence/CloudKitErrorMapper.swift`

```swift
import CloudKit
import Foundation

/// M7.3.4: Single source of truth for CloudKit error messages
/// Replaces duplicate mapping in CloudKitSyncMonitor and CloudKitDiagnostics
struct CloudKitErrorMapper {

    /// Error classification for retry behavior
    enum ErrorType {
        case transient      // Will resolve itself, CloudKit retries
        case userAction     // Requires user action (sign in, free storage)
        case permanent      // Won't resolve without code change
    }

    struct MappedError {
        let userMessage: String
        let type: ErrorType
        let suggestedAction: String?
    }

    /// Maps CKError to user-friendly message and classification
    static func map(_ error: CKError) -> MappedError {
        switch error.code {
        case .networkUnavailable:
            return MappedError(
                userMessage: "No internet connection. Changes will sync when you're back online.",
                type: .transient,
                suggestedAction: nil
            )

        case .networkFailure:
            return MappedError(
                userMessage: "Network error. Will retry automatically.",
                type: .transient,
                suggestedAction: nil
            )

        case .notAuthenticated:
            return MappedError(
                userMessage: "Not signed into iCloud. Please sign in to enable sync.",
                type: .userAction,
                suggestedAction: "Open Settings → [Your Name] → iCloud"
            )

        case .quotaExceeded:
            return MappedError(
                userMessage: "iCloud storage full. Please free up space to continue syncing.",
                type: .userAction,
                suggestedAction: "Open Settings → [Your Name] → iCloud → Manage Storage"
            )

        case .zoneBusy:
            return MappedError(
                userMessage: "iCloud is busy. Will retry automatically.",
                type: .transient,
                suggestedAction: nil
            )

        case .serviceUnavailable:
            return MappedError(
                userMessage: "iCloud service temporarily unavailable. Will retry shortly.",
                type: .transient,
                suggestedAction: nil
            )

        case .serverRecordChanged:
            return MappedError(
                userMessage: "Someone else edited this. Changes merged automatically.",
                type: .transient,
                suggestedAction: nil
            )

        case .zoneNotFound:
            return MappedError(
                userMessage: "Sync zone not found. Recreating...",
                type: .transient,
                suggestedAction: nil
            )

        case .unknownItem:
            return MappedError(
                userMessage: "Item not found. It may have been deleted.",
                type: .permanent,
                suggestedAction: nil
            )

        case .internalError:
            return MappedError(
                userMessage: "iCloud internal error. Will retry shortly.",
                type: .transient,
                suggestedAction: nil
            )

        case .serverRejectedRequest:
            return MappedError(
                userMessage: "Server rejected request. Please try again later.",
                type: .transient,
                suggestedAction: nil
            )

        case .participantMayNeedVerification:
            return MappedError(
                userMessage: "Invitation recipient needs to verify their iCloud account.",
                type: .userAction,
                suggestedAction: "Ask them to check their iCloud settings"
            )

        default:
            return MappedError(
                userMessage: "Sync error (\(error.code.rawValue)). Will retry automatically.",
                type: .transient,
                suggestedAction: nil
            )
        }
    }

    /// Convenience method for extracting CKError from any Error
    static func map(_ error: Error) -> MappedError? {
        if let ckError = error as? CKError {
            return map(ckError)
        }
        return nil
    }
}
```

**Update CloudKitSyncMonitor.swift**:
```swift

// With:
```

```swift
import OSLog
import CloudKit

/// M7.3.4: Structured logging for CloudKit operations
/// Uses OSLog for retrieval from TestFlight devices
struct CloudKitLogger {
    private static let logger = Logger(
        subsystem: Bundle.main.bundleIdentifier ?? "com.richhayn.forager",
        category: "CloudKit"
    )

    // MARK: - Household Operations

    static func householdCreated(_ household: Household) {
        logger.info("✅ Household created: \(household.name ?? "unnamed", privacy: .public)")
    }

    static func householdLeft(_ householdID: String) {
        logger.info("👋 Left household: \(householdID, privacy: .public)")
    }

    static func householdDeleted(_ householdID: String) {
        logger.info("🗑️ Household deleted: \(householdID, privacy: .public)")
    }

    static func memberInvited(email: String, householdID: String) {
        logger.info("📧 Invited member to household: \(householdID, privacy: .public)")
        // Note: Don't log email for privacy
    }

    static func memberRemoved(householdID: String) {
        logger.info("❌ Member removed from household: \(householdID, privacy: .public)")
    }

    static func memberJoined(householdID: String) {
        logger.info("🤝 Member joined household: \(householdID, privacy: .public)")
    }

    // MARK: - Share Operations

    static func shareCreated(recordID: String) {
        logger.info("📤 CKShare created: \(recordID, privacy: .public)")
    }

    static func shareAccepted(recordID: String) {
        logger.info("📥 CKShare accepted: \(recordID, privacy: .public)")
    }

    static func shareFailed(operation: String, error: Error) {
        if let ckError = error as? CKError {
            let mapped = CloudKitErrorMapper.map(ckError)
            logger.error("❌ Share operation '\(operation, privacy: .public)' failed: \(mapped.userMessage, privacy: .public) (code: \(ckError.code.rawValue))")
        } else {
            logger.error("❌ Share operation '\(operation, privacy: .public)' failed: \(error.localizedDescription, privacy: .public)")
        }
    }

    // MARK: - Sync Events

    static func syncStarted() {
        logger.debug("🔄 Sync started")
    }

    static func syncCompleted(recordCount: Int) {
        logger.info("✅ Sync completed: \(recordCount) records")
    }

    static func syncFailed(error: Error) {
        if let ckError = error as? CKError {
            let mapped = CloudKitErrorMapper.map(ckError)
            logger.error("❌ Sync failed: \(mapped.userMessage, privacy: .public) (code: \(ckError.code.rawValue))")
        } else {
            logger.error("❌ Sync failed: \(error.localizedDescription, privacy: .public)")
        }
    }

    // MARK: - Debug

    static func debug(_ message: String) {
        logger.debug("\(message, privacy: .public)")
    }

    static func warning(_ message: String) {
        logger.warning("⚠️ \(message, privacy: .public)")
    }
}
```
