# M9.0.1: Recipe Picker Scalability Fix

**Status**: ACTIVE
**Created**: February 21, 2026
**Type**: Bug fix (UX regression from M15.5)
**Estimated**: 30-45 min
**Branch**: `feature/M9.0.1-recipe-picker-fix`

---

## Problem

The M15.5 meal plan rewrite introduced two recipe pickers that don't scale:

1. **"Choose Recipe" (unplanned days)**: SwiftUI `Menu` popover showing max 20 recipes with no search. With 2 recipes it works; with dozens it's unusable.
2. **"Swap" (planned days)**: Inline `List` showing max 30 recipes with no search. Same scalability issue.

Meanwhile, `RecipePickerSheet.swift` (built in M4.2) already has everything needed: search-as-you-type, scrollable list, per-recipe servings adjuster, household scope filtering, and empty states. It's just not wired up.

## Root Cause

During the M15.5 MealPlanDetailView rewrite, the existing `RecipePickerSheet` was not integrated. Two simpler pickers were inlined instead, likely for speed during the UX overhaul.

## Solution

### 1. Refactor RecipePickerSheet to Pure Picker

Currently `RecipePickerSheet` calls `MealPlanService.shared.addRecipeToMealPlan` internally. This conflicts with the swap flow (which must remove the existing meal first, since the service refuses to add when a date already has a meal).

**Change**: Make `onRecipeSelected` return `(Recipe, Int)` (recipe + servings). Remove the internal save. Let the parent handle all mutation.

### 2. Inline Search-as-You-Type for Unplanned Days

Each unplanned day card gets an inline TextField with autocomplete:
- Magnifying glass icon + "Search recipes…" placeholder
- As user types, filtered results appear directly below (max 5 shown)
- Each result shows recipe name, ingredient count, and serving size
- Tap a result to add the recipe with default servings
- Search text clears and keyboard dismisses on selection
- Date-based `@FocusState` handles multiple unplanned days visible simultaneously
- `onChange(of: focusedSearchDate)` clears text when switching between day fields

### 3. RecipePickerSheet for Swap Flow

Planned days use the full RecipePickerSheet as a modal sheet for swapping recipes, since there's no inline search visible on planned day cards.

### 4. Clean Up Dead Code

- Remove old `Menu` popover and inline swap picker
- Remove `swapDate` and `showSwapPicker` state

## Files Modified

| File | Change |

| `forager/RecipePIckerSheet.swift` | Remove internal save, change callback signature |
| `forager/MealPlanDetailView.swift` | Inline search for unplanned days, RecipePickerSheet for swap |

## Testing

- Build succeeds with zero warnings
- Choose Recipe on unplanned day → type in search field → results appear inline
- Tap result → recipe appears on day card, search clears
- Swap on planned day → presents search sheet → old meal replaced
- Cancel from picker → no changes (meal preserved for swap)
- Multiple unplanned days: focus switches cleanly between day cards
- Search filters recipes correctly (case-insensitive substring match)
- Empty search text shows no results (clean state)
