# M10.6.12: Recipe Import Bug Fixes

**Status**: ACTIVE
**Priority**: High — user-facing bugs found during device testing
**Estimated effort**: ~1 hour (6 targeted fixes)

## Context

User testing on device with Pinch of Yum "Spicy Shrimp Tacos" recipe revealed 6 bugs in the recipe import flow. Core issues span the template creation pipeline, UI dismissal, scrolling, missing controls, and confusing status indicators.

## Fixes

### Fix 1: Ingredient templates invisible in household context

Three related sub-bugs in the template creation pipeline:

**1a: Fallback path missing householdKey**
- File: `Services/IngredientTemplateService.swift`
- `findOrCreateTemplate()` catch block creates fallback templates without `householdKey`
- Fix: Add `template.householdKey = resolvedHouseholdKey` to fallback path

**1b: Double usageCount increment**
- Files: `Services/Import/RecipeImportService.swift`, `Services/IngredientParsingService.swift`
- `findOrCreateTemplate()` already increments `usageCount += 1`, then callers call `incrementUsage()` again
- Fix: Remove redundant `templateService.incrementUsage(template:)` calls at both import sites

**1c: `awakeFromInsert()` can set nil householdKey**
- File: `Models/IngredientTemplate+Extensions.swift`
- When `Household.id` is nil (common with CloudKit child contexts), sets `householdKey = nil`
- Fix: Guard with `if let key = existingHousehold.id?.uuidString`

### Fix 2: Browser doesn't dismiss after import

- File: `forager/Views/Import/RecipeBrowserView.swift`
- `RecipeBrowserView` presents `RecipeImportSheet` as nested `.sheet()`. Only sheet dismisses on save.
- Fix: Track save state via `onChange(of: importService.state)`, dismiss browser in `onDismiss` callback

### Fix 3: "Add Step" appears non-functional

- File: `forager/Views/Import/RecipeImportPreviewView.swift`
- Code works correctly but view doesn't scroll to show new step at bottom
- Fix: `ScrollViewReader` + tag Add Step button + `scrollTo` with delay after adding

### Fix 4: No "Add Ingredient" button

- File: `forager/Views/Import/RecipeImportPreviewView.swift`
- No way for user to manually add ingredients during import preview
- Fix: Add button after ForEach, `addImportIngredient()` method, filter empties on save

### Fix 5: Confusing status indicators

- File: `forager/Components/IngredientMatchRow.swift`
- Green checkmarks look like checkboxes to users
- Fix: `.ready` → invisible spacer, remove "N ready" from summary, hide summary when all ready

### Fix 6: Match count accuracy

- File: `forager/Views/Import/RecipeImportPreviewView.swift`
- `computeIngredientMatches()` skips nil results from short texts, making counts incomplete
- Fix: Create fallback `IngredientMatchResult` with `.needsTemplate` for nil results
